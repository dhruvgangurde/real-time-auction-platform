# Demo photo credits

The first four are copies of the CC0 images in `design/mockups/images/`, whose licences were read from each object's record on 2026-10-13. The two from the Cleveland Museum of Art's open access API were read from each object's record on 2026-10-17 (`share_license_status: CC0`) and are its web-size images, unchanged.
